# Dazai's Elevator of Suffering 🛗🩹

A highly interactive, beautifully styled web-based simulation of **Dazai Osamu** (from *Bungo Stray Dogs*) trapped in the Armed Detective Agency's Elevator Shaft B-4. Experience his inner monologues, vitals monitoring, and chaotic encounters in a sleek, retro-modern terminal aesthetic.

## Features ✨

- **Interactive Floor Call Panel**: Control the elevator between 6 floors with smooth CSS transition physics.
- **Dazai's Vitals Tracking**:
  - **Will to Live**: Fluctuates dynamically based on events (from elevator motion to encountering coworkers).
  - **Bandage Rolls Consumed**: Bandages are applied or lost during chaotic activities.
  - **Death Attempts Logged**: Comedic counters keeping track of his dramatic antics.
- **Dynamic Speech Bubble & Monologues**: Features over 40 context-aware quotes and idle mutterings categorized by states (ascending, descending, door operations, and more).
- **Special Interactions & Events**:
  - ✦ **Compose Poetry**: Triggers a drama sequence where Dazai writes an elevator-themed haiku.
  - ✦ **Achieve Chaos**: Simulates pressing all floor buttons at once, leading to elevator turbulence and a rapid floor tour.
  - ✦ **Escape Attempt**: Comedic ceiling hatch escape sequence that invariably gets caught in Dazai's bandages.
  - ✦ **Akechi Enters**: Adds Akechi into the 2m² elevator space, peaking the tension to maximum with zero-word arguments.
- **Detailed Live Event Log**: Real-time terminal output with custom-coded entry categories (`info`, `move`, `drama`, `panic`, `lol`).

## Running Locally 🚀

Simply open the [index.html](index.html) file directly in any modern web browser! No installation or server required.

```bash
# Clone the repository
git clone https://github.com/Mr-Soumo-006/dazai_elevator.git

# Open the project
cd dazai_elevator
start index.html
```
